# ADR 0002: Go 1.27, pinned to its patch version

- **Status:** accepted
- **Date:** 2026-10-28

## Context

Go 1.27 is the current stable release (1.27.3). A build must be reproducible: the same commit has to produce the same binary on a laptop, in CI and in the Docker image.

## Decision

- `go.mod` declares `go 1.27.3`. With the default `GOTOOLCHAIN=auto`, Go downloads that exact toolchain when an older one is installed.
- CI reads the version from `go.mod`.
- The Docker build stage uses `golang:1.27.3-alpine`, and the Makefile builds the linters with the same toolchain.
- An update changes `go.mod`, the `Dockerfile` and the `Makefile` in the same pull request. `govulncheck` in CI reports standard library vulnerabilities fixed in a newer patch.

## Consequences

- Every environment compiles with the same toolchain.
- The version appears in three files, which the update pull request changes together.

## Alternatives considered

- **`go 1.27` without a patch version:** each environment would compile with whatever 1.27 patch it had installed.
